Pancakes keeps a project's documents in one place. A Google Doc serves as the table of contents, and every document it links to opens in the same page, beside a sidebar listing the rest. It handles Docs, Sheets and Slides, Figma files, YouTube and Drive videos and external sites.

It is made for handing a project over. The documentation becomes one link, and it can be deployed inside an organization's own domain when access needs limiting.

Google Apps Script and the Google Docs API; a small GitHub Pages frame in front. 2021.
