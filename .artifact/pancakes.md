Documentation scatters. Wikis nest, note apps branch, and the thing you wanted someone to read ends up four clicks deep. Pancakes keeps the pile in one place: a Google Doc serves as the table of contents, and every document it links to opens in the same page, beside a sidebar listing the rest. Docs, Sheets and Slides, Figma files, YouTube and Drive videos, external sites.

It is made for handing over. A project's documentation becomes one link, and it can be deployed inside an organization's own domain when access needs limiting.

Google Apps Script and the Google Docs API; a small GitHub Pages frame in front. 2021.
